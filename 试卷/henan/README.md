# 河南省历史试卷

本目录的试卷内容整合在上级目录的 `../henan_full.md` 文件中。

## 文件来源

- `henan_full.md`（位于 `documents/试卷/`）：由用户上传的原始 Markdown 文件复制而来，包含 2021—2026 年河南高考历史真题及 2025、2026 两套模拟卷。

## 试卷构成

- 2021年高考历史试卷（全国乙卷）—— 适用于河南
- 2022年高考历史试卷（全国乙卷）—— 适用于河南
- 2023年高考历史试卷（全国乙卷）—— 适用于河南
- 2024年高考历史试卷（新课标卷）—— 适用于河南
- 2025年高考历史试卷（河南卷）
- 2026年高考历史试卷（河南卷）
- 2025年历史模拟卷（无标准答案，构建时排除）
- 2026年历史模拟卷（无标准答案，构建时排除）

## 构建说明

构建脚本 `tools/build-history-bank-henan.mjs` 直接读取 `documents/试卷/henan_full.md`，按配置文件 `tools/paper-config-henan.json` 解析选择题并归类到教材单元。仅 2021—2026 年六份真题进入练习题库；图表题和无答案的模拟卷题目均排除。
