# 2024年高考历史试卷（河北卷）


> 以下为2024年河北省普通高中学业水平选择性考试历史试题完整内容。

### 选择题

**1.** 据考古发掘，距今约9000年前的浙江上山、河南贾湖等遗址，出土了中国特有的制作榫卯结构工具石凿；距今8000至7000年前的浙江跨湖桥、河姆渡等遗址，发现了榫卯木结构建筑。之后，此类建筑在中华大地广泛分布、成为中国最典型的建筑形式之一。这主要体现了，中华文化具有

A. 本土性和包容性  B. 多样性和连续性
C. 本土性和连续性  D. 多样性和包容性

**答案：** C

**解析：** 榫卯结构建筑从9000年前出现，到7000年前成熟，此后在中华大地广泛分布，成为中国最典型的建筑形式之一，体现了中华文明的本土性和连续性，C项正确。故选C项。

**答案：** D

**解析：** 这一选官都是通过考察知识、能力和实际表现来选官的，重在选拔有实际行政能力的人才，D项正确。故选D项。

**3.** 南北朝之前，"川"字只有"水道、河流"之意，而《魏书》所载牛川、宁川、敕勒川等地名中的"川"，则是鲜卑语"荒野、荒滩草原"的意思。于是，"川"字有了新的义项，并沿用至今。这主要反映出，民族交融

**解析：** "川"字在《魏书》中被赋予了鲜卑语中"荒野、荒滩草原"的新意，体现了随着民族间的交融，语言文化得到了丰富和发展，C项正确。故选C项。
