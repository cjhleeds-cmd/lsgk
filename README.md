# 历史长河 · 高考历史闯关

一个面向各省高考历史学习的闯关答题网页，当前先提供**广东版**（统编版教材）。项目采用纯 HTML、CSS、JavaScript 编写，运行无需安装依赖或执行构建命令。

## 运行方式

```bash
# 直接打开
双击 index.html 或 历史长河.html

# 本地服务器
python3 -m http.server 8080
# 访问 http://localhost:8080/
```

## 切换省份

首页提供省份选择器占位，当前仅支持广东版。后续可在 `data/题库.js` 和 `data/游戏机制.js` 中增加其他省份配置，并通过省份切换器加载。

## 内容填充路径

1. **题目**：通过 `题库编辑器.html` 逐单元添加，或批量导入 Markdown 试卷后替换 `data/题库.js`
2. **历史现场**：在 `data/讲历史.js` 中按教材单元补充 `TEACH_SCENES` 情境
3. **图片**：替换 `assets/` 下同名图片即可，框架已映射 38 张单元配图 + 5 张首页封面

## 与原项目的区别

本项目基于「历史长河·华侨港澳台联考版」的代码框架改编：
- 教材结构从联考大纲切换为统编版高中历史 5 本教材
- 地图模块从 3 个（中国古代史/中国近现代史/世界史）扩展为 5 个（对应 5 本教材）
- 单元从 29 个扩展为 38 个
- 增加省份切换 UI 占位
- localStorage key 独立，不与原项目数据冲突
